# AK506 Nano documentation

This directory contains the documentation that ships with the AK506 Nano
source tree. Start with the root [README](../README.md) for hardware, build and
programming instructions.

## Supported configuration

`dsPIC33AK512MPS506_CLASSIC_DRC` is the only hardware-qualified and supported
target. Other configurations may remain in the source tree as
legacy/regression material; their presence does not imply support.

| Document | Use it for |
| --- | --- |
| [AK506 Nano validation](ak506_nano_validation.md) | Validated DRC load, CSV transfer behaviour and the running-audio boundary. |
| [AK506 Nano test procedure](ak506_nano_test.md) | Build, programming and focused Nano acceptance procedure. |
